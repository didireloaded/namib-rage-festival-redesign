# Suggested AGENTS.md instruction

When working on a website, landing page, web application, responsive interface, UI redesign or design audit:

1. Read `.agents/skills/website-design-craft/SKILL.md` and the references relevant to the task.
2. Build around real brand, content and user goals, not a generic AI-generated template.
3. Apply the 20-item anti-slop checklist and select motion deliberately from the 20-pattern motion playbook.
4. Design and test mobile, tablet and desktop behavior, plus keyboard, reduced-motion, empty/error/loading states.
5. Do not invent business facts, testimonials, product imagery, metrics or integration success.
6. When asked to plan, do not code. When asked to implement, follow the existing stack and verify before completion.
